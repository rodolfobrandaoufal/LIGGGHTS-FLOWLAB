// ----------------------------------------------------------------------------
// LIGGGHTS static contact-model whitelist (tracked in git).
//
// Each GRAN_MODEL(normal, tangential, cohesion, rolling, surface) line is
// compiled as a fully inlined ContactModel<GranStyle<...> > for pair gran and
// wall/gran. Any combination NOT listed here still runs, through the slower
// runtime-composed fallback, which prints a one-time warning naming the line
// to add here.
//
// Consumers:
//   * Make route  : src/Make.sh ("make <machine>" -> Make.sh models) uses this
//                   file when no local src/style_contact_model.whitelist exists,
//                   then merges style_contact_model_user.whitelist and
//                   style_contact_model_autoExamples.whitelist.
//   * CMake route : src/cMake/Model.cmake WRITE_WHITELIST reads this file by
//                   default (cache variable LIGGGHTS_CONTACT_WHITELIST); the
//                   legacy ENABLE_MODEL_* cross product is used only with
//                   -DLIGGGHTS_CONTACT_WHITELIST_FROM_OPTIONS=ON.
//
// Only lines starting with GRAN_MODEL( are entries; '//' lines are comments.
// SURFACE_SUPERQUADRIC entries compile in every build (a dummy surface model
// raises a run-time error when superquadric support, ENABLE_SQ /
// SUPERQUADRIC_ACTIVE_FLAG, is not compiled in).
// Compile cost: ~0.33 s and ~26 kB of text per entry in lammps.cpp (PF-07).
//
// Curated list of the modernization branch (124 entries, formerly the
// untracked src/style_contact_model.whitelist) plus the entries below it.
// ----------------------------------------------------------------------------
