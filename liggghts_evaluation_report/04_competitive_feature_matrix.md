# Comparative Capability Analysis

## IP boundary and sources

This comparison uses only public, high-level concepts from vendor/project documentation. It does not reproduce proprietary algorithms, source code, interfaces, or documentation text.

Public sources consulted:

## Strategic implications

- LIGGGHTS remains scientifically valuable because it is scriptable, open, LAMMPS-compatible in style, and rich in granular contact models.
- Commercial tools emphasize workflow, material libraries, GPU/multi-GPU performance, and integrated multiphysics. LIGGGHTS can compete by being transparent, reproducible, and extensible rather than by copying proprietary interfaces.
- The highest-impact capability gaps are not only new physics. They are validated workflows: calibration, scalable output, automated benchmarks, and modern coupling APIs.
